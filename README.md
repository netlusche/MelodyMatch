# MelodyMatch

A fast-paced, interactive, modern local-multiplayer music quiz built with React, Vite, and the iTunes API.

## Features
- **Real iTunes Music**: Plays real song snippets directly from iTunes via JSONP, completely bypassing standard CORS and Adblocker protections.
- **Dynamic Options**: Vast 100-song multiple-choice option arrays guarantee unprecedented district distractor variety across any selected round length.
- **Flawless Integrities**: Deep RegExp string cross-referencing algorithms explicitly obliterate duplicate tracks natively hidden across different iTunes compilation records.
- **Regions**: Deeply localized (EN/DE) setup and fully localized native API queries, injecting region-specific genres (e.g., *Schlager*, *Neue Deutsche Welle*, *Ballermann*) directly into German clients.
- **Aesthetic**: Gorgeous glowing glassmorphic components and `canvas-confetti` fireworks engine for a premium presentation.

## Usage

### Local Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
*(Compiled under `. / dist`. Out of the box, `vite.config.ts` has been natively pre-configured with a relative base path `<base: './'>` indicating full inherent support for frictionless subdomain or subdirectory-hosted deployments!)*
